# ODDAWURLD - Next-Gen Electrical & Hardware E-Commerce

A luxury, futuristic e-commerce website for architectural lighting, modular switches, circuit protection, and smart home hardware. Built with React, Vite, and Tailwind CSS.

## 🎨 Theme & Palette
- **Main Background:** Deep Midnight Navy (`#07111F`)
- **Section Backgrounds:** Dark Navy (`#0B1928`)
- **Cards & Containers:** Deep Blue-Black (`#102334`)
- **Primary Accent:** Electric Cyan (`#43D9FF`)
- **Secondary Accent:** Ice Blue (`#A6E9F5`)
- **Main Text:** White (`#FFFFFF`)
- **Secondary Text:** Soft Grey (`#B8C5D1`)
- **Borders & Dividers:** Subtle Blue-Grey (`#294252`)

## ⚡ Features
- **Hero Staging:** 3D studio pedestal presentation with glowing cyan rings, dappled gobo lighting, and interactive specification hotspots.
- **Category Navigation:** 5 sleek glassmorphic category cards resting on pedestal contact shadows.
- **Product Catalog:** Comprehensive electrical inventory with live search, category sidebar filters, price slider ($20–$150), in-stock toggle, and sorting.
- **Product Detail:** Multi-angle gallery thumbnail switcher, technical specifications table, safety standards breakdown, and contractor reviews.
- **Persistent Shopping Cart:** LocalStorage cart with quantity controls, coupon engine (`VOLT10`, `POWER20`), and free express shipping threshold calculator.
- **Validated Checkout:** Complete multi-step shipping and payment flow with instant feedback.
- **Live Order Tracking:** 5-step interactive tracking timeline and order reference lookup.
- **Fully Responsive:** Custom tailored layouts for Desktop (1440px/1024px), Tablet (768px), and Mobile (390px/360px).

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/g80643067-art/demoelectrics-.git

# Navigate into the project directory
cd demoelectrics-

# Install dependencies
npm install

# Start local dev server
npm run dev
```

### Production Build
```bash
npm run build
```
